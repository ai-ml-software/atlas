# ALTUS client deliverables

- `android/ALTUS-1.0.0-release.apk`: signed, self-contained ARM64 Android release build of the current preview. Installation details and verification are in `android/BUILD-REPORT.md`.
- `ALTUS-Client-Presentation.pdf`: 69 branded pages, covering every registered screen with English/Arabic views and its practical benefit; includes global catalogs and an explicit release roadmap.
- `ALTUS-Client-Walkthrough.mp4`: 1080p narrated screen walkthrough, approximately 12 minutes 50 seconds, covering all 110 screens with Arabic views alongside English.
- `ALTUS-Client-Walkthrough.srt`: English subtitles.
- `ALTUS-All-Screens.jpg`: overview of all 110 English screen captures.
- `screens/`: actual English/Arabic captures and responsive/dark views.
- `languages.json` / `countries.json`: complete selectable catalogs. English/Arabic interface translations are implemented; other languages disclose English fallback.
- `capture-manifest.json` / `api-checks.json`: browser and isolated API evidence.

Present these as a working product preview. The demonstration property, learning content and figures are illustrative. Production integration and device validation status is documented in `../FINAL-AUDIT.md`. Signing credentials are not included.
